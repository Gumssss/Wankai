| 起测强度 | 球6 HP/次，同目标先分离且至少间隔.6 s；速度18 m/s，半径.46 m | 70°、3.4 m范围，每累计.25 s有效暴露2 HP，吃满最多20 HP；无离场尾伤 |

| 资源 | 40体力 / 30 s冷却；主动移动不叠加普通挥武器费用 | 35体力 / 24 s冷却；普通挥武器/转向费用照常 |

| 装备 | 足球及六种通用武器；全都在主动期收起，结束安全恢复 | 皇冠爱心及六种通用武器；香水瓶为额外技能道具 |

这些数值是首轮测试参数，玩法方向已选。只在这两个技能内部依据实测微调，不改其他角色与全局平衡。F释放不取消，额外F不续期；不足体力/冷却/恢复中拒绝激活且不扣费，接受激活后立即扣费计CD，中断不退款。两技能前摇/主动/收招禁回体力，之后按原恢复延迟处理。

CR7仅在地面或有效地面武器支撑时启动。球低位运动，不碰施放者；首版不增加武器拦球、球球碰撞、追踪或夺取归属。无敌免HP伤害与攻击附加击退/硬直，但不取消重力、地面/墙/障碍/角色的必要分离，也不免奶蛙的非伤害体力压制。球到期与无敌结束必须同tick；球被卡住也不能延长保护。

香水以喷口为基准做有限高度的扇形体积判断，按敌方受击体积相交与实体遮挡计算；不使用无限高地面圈。离开即停止累计暴露，保留该次施法已累计的不足一跳余量，重进不白送瞬时伤害；技能到期丢弃不足.25 s的余量。镜像双方的雾各自结算，雾不伤施放者。前摇被有效伤害取消；主动喷雾可通过移动/击退错开，不加额外击退或眩晕。

## 2. 实施顺序和每步完成标准

### A. 固定基线与共用支持

- 开工先重新检查HEAD、工作树、仓库指令及选定记录；保留图标/图片/遗留未跟踪文件和共享node_modules，不清理或切错旧Wankai目录。
- 在修改前运行现有回归与构建，记录新基线；历史177测试不冒充本次结果。已有失败先归因，避免把它们混入新技能问题。
- 增加两技能明确的前摇/主动/收招/冷却状态与激活ID，集中首轮参数；保留现有五技能时序。
- 扩展投射物类型分发（外卖箱/足球），原外卖箱仍按原规则碰撞后消失。显示层不得把所有投射物继续画成外卖箱。
- 建立窄范围的统一伤害许可检查，覆盖武器/外卖箱/足球/香水；物理分离与HP/附加击退分开。前摇末帧受击与出球同tick时优先受击取消，用测试锁定顺序。
- 输入保留原始WASD按住位掩码及朝向，避免从已镜像的武器theta反推技能移动。W+S=0不是松开；结束输入门必须看真实位掩码。

涉及：`src/skills.js`、`src/physics.js`、`src/game-session.js`、`src/character-catalog.js`、`src/loadouts.js`。新增专用模块按实际复杂度拆分，不先重写整个技能框架。

**完成标准：** 新的共用数据结构和旧行为回归通过；原有五技能、普通武器与正常输入不变。

### B. 先完成 Mean Girl 的真实喷雾

- 按固定1/180 s时间推进喷头跟转、暴露累计、持续伤害和生命周期。
- 用真实受击形状与有限体积检测；对墙/柱做战斗用遮挡，不直接把相机的15段采样遮挡当精准战斗检测。
- 角色和所有装备保持原接触形状；瓶子是视觉道具，不撑地、不格挡；雾粒子只做显示，不逐粒子联网/算伤害。
- 验证完整暴露、边缘/侧后方/高低差、离开重进、掩体、前摇中断、死亡清理及两人同时喷雾。

**完成标准：** 在真实场景中可见“喷口方向→雾范围→持续扣血”；离开/遮挡立即停止新增暴露，满时长20 HP，无重进瞬伤漏洞。

### C. 完成 CR7 的反弹球、无敌与直接移动

- 球使用连续扫掠找最早接触，反射速度并处理该步剩余时间；限制同tick求解次数、纠正重叠，防穿墙、角落振荡和零时间无限反弹。球的视觉中心/半径与碰撞一致。
- 碰场地边界、障碍、敌方身体后继续存在；伤害冷却与物理反弹分开；无敌目标仍能反弹球，但不扣HP。
- 主动期移除普通武器攻击/支撑/碰撞与旧角速度；施加明确的技能水平移动，走原有地面/边界/障碍/角色分离路径，不直接穿墙改位置。保留垂直重力与落地，不加入新跳跃。
- 相机平面WASD、对角归一化、松开停止、反向、对向键抵消；区分主动移动与外力、地面约束，避免通过清空整个速度抹掉重力。
- 到期移除球/免伤/主动移动，.3 s收招后安全恢复装备。恢复姿态、重叠和接触门不得造成凭空攻击；按键清空门支持真实按键、AI和网络输入。
- 验证实际半径19.35 m场地、全部现有场景、墙角、贴墙目标、快速球路、同tick命中与到期、镜像两球及所有伤害入口。压缩预览不作为命中率依据。

**完成标准：** 真正可操作的3 s走位窗口；球打人后继续弹；所有伤害源均正确免伤；到期不误挥，不穿模、不无限无敌。

### D. 完成动画、道具、特效与HUD

- 在已批准CR7模型上补最小腿部绑定、踢球和移动循环；保留原模型与纹理，另存工作源/导出，不重新生成角色。动作无root-motion，物理/技能控制拥有身体位置。
- 现有导入器提取静态geometry，不能直接播放蒙皮：为CR7增加保留skeleton/clip的加载和实例克隆路径，避免两名CR7共用骨骼；原静态角色加载路径继续使用。
- 对起脚、脚触球、出球、移动、停止、收招制作补充动作短片，检查脚底、膝关节、球心、武器恢复与身体受击范围。若受击形状不变，动作必须保持在合理包络内，不能让可见动作大幅脱离命中范围。
- Mean Girl整理独立香水瓶、喷嘴方向、粉色雾与范围提示；保持脸/衣服/皇冠爱心不变，普通武器与喷瓶避免互相遮挡。
- HUD明确“WASD移动”、剩余无敌时间、冷却、结束后“松开再按”。特效/音效由权威事件驱动，所有审阅预览保持静音。

**完成标准：** 不是只让刚体滑动的最终交付；模型实例独立、外观保留、动作与实际技能阶段对齐，反馈不遮挡战斗。

### E. 联机和AI接入

- host唯一权威：输入校验、移动、伤害、免伤、暴露累计、球反射和清理都在原固定步进；guest不自算HP或球命中。
- 输入扩展原始按键掩码/技能边沿信息及相机朝向，校验位域和有限值；不接收客户端直接位置/无敌声明。菜单/失焦归零输入，重复与过期激活不能二次扣费。
- 快照增加投射物类型/反弹序号/生命周期、技能阶段、免伤/收武器/输入重置门、喷头状态；精简字段，避免发送雾粒子。反弹段断点不能跨墙直线插值。
- 协议由5升至6并拒绝旧协议；测试host/guest两边都能操作CR7和Mean Girl、两个同角色及交叉对战。
- AI走同一输入合同；CR7会在主动期走位并在结束后释放重按，Mean Girl会对准近处敌人；对手根据可见状态躲雾/球，不读取未来输入。

**完成标准：** host/guest状态一致、无重复伤害和残留保护；AI能完整激活、使用、退出技能，仍有种子可复现性。

### F. 回归、实战视频与最终记录

- 针对技能数学/生命周期写有意义的测试，再跑完整 `npm test` 与 `npm run build`；发生新改动/失败才按需重测。重点覆盖现有combat、session、network、AI、models、restored-animals、drive-characters与audio测试。
- 两角色各7种合法装备全部覆盖；新的错误装备不放行。覆盖体力刚好/不足、重复F、连续持键、对向键、前摇命中、消失/恢复同tick、暂停/失焦、死亡/结果、重开/重赛、断连。
- 录制实际游戏：完整W/S/A/D/WA/WD/SA/SD、技能组合输入、成功/躲避/中断、结束重按门、球打人后反弹、雾遮挡与离开停伤。正常速度后保留相同事件慢放，输入/地面/身体响应/资源/真实伤害可见；检查编码后时间码。
- 比较选定预览与真实游戏；更新README、技能说明、架构/协议、角色记录、模型来源与验证日志，明确“选定/已实现/已验证/用户实玩接受”四个状态。
- 本机loopback可验证网络合同，不冒充Steam双机或用户MacBook验证。Native Steam只在环境确实具备且实际测试后报告。

**完成标准：** 两技能本地可玩、回归/构建通过、实际游戏视频存在且已检查、记录可接续。保持本地交付；发布/推送不包含在本次范围。

## 3. 执行依赖与风险

顺序：A → B → C → D → E → F。联机字段在A阶段确定接口，E阶段完成集成，避免最后才改输入合同。先完成香水可验证持续伤害入口，再用于CR7跨技能无敌回归。

最大风险为CR7连续反弹、结束按键门和静态网格转骨骼加载；不以渲染隐藏物理错误，不把“球画出来了”当作反弹完成。若原模型腿部拓扑导致权重质量不足，先保留批准外观做局部修整与短片验证，不直接重造角色。

本计划把已接受控制语义作为固定目标；数值微调留在两技能参数内。新增跳跃、追踪球、地面毒池、其他角色技能和全局战斗重构都不混入本次实施。
