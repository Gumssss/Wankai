# 丸棍竞技场

一个可以离线运行的 Electron 3D 物理对战原型。界面使用 React，角斗场由 React Three Fiber 和 Three.js 渲染，固定时间步的自定义约束物理计算撑地、挥棍与碰撞。菜单提供分屏双人对战、固定视角双人对战、木桩练习和单人自由视角。

## 启动

需要 macOS 和 Node.js 22.12 或更新版本。首次安装依赖后，在此目录运行：

```sh
npm install
npm run dev
```

Vite 会在 `127.0.0.1:5173` 启动本地开发服务器，Electron 会自动打开游戏窗口。修改 React 或场景代码会热更新。关闭开发环境时，在终端按 `Ctrl+C`。安装依赖需要联网；安装后，游戏运行不需要联网。

运行 `npm test` 检查物理规则，运行 `npm run build` 验证渲染器构建。本阶段提供可玩的开发应用，不生成安装包。

## 操作

| 操作 | 赤丸 P1 | 青丸 P2 |
| --- | --- | --- |
| 在角色面向的竖直平面内，向正面连续挥动 | W | ↑ |
| 在同一平面内，向背面连续挥动 | S | ↓ |
| 水平向左转动武器朝向 | A | ← |
| 水平向右转动武器朝向 | D | → |
| 转动自己的分屏镜头（松开保持角度） | Q / E | . 和 /（? 所在键，无需 Shift） |
| 暂停 / 继续 | Esc | Esc |
| 重新开始 | R | R |

双人对战默认赤丸使用短剑、青丸使用原有的 Tripo 长柄刀。「兵器库」展示实际模型、打法、所长与取舍，双方可分别选择，也可使用同一种兵器。进入对战、练习或单人模式前会先打开选择界面；重开保留双方选择，回主菜单后可更换。可选短剑、长柄刀和新铁战锤。短剑的碰撞长度更短，转动加速、刹车和最高角速度更高；铁战锤起挥与收招更慢，宽头参与命中、格挡和撑地，金属头命中伤害提高 30%；角色没有额外移动速度，仍靠武器触地移动。短剑撑地时的手感仍待实玩确认，历史问题及检查见[短剑试验记录](docs/SWORD_TRIAL.md)。

W / S（↑ / ↓）不再指定上抬或下砸的目标角度。武器在头顶时，W 选择朝角色正面的一侧挥下，S 选择背面的一侧；继续按住同一键，可以越过竖直向下的位置，借地面接触撑起身体并转向另一侧。松手后保留角速度，受重力和阻尼影响；按反方向会先刹车再反转。W 和 S 同时按视为没有竖直方向输入。暂停、失焦会清除按键。

A / D（← / →）只改变武器的水平朝向，可以与 W 或 S 同时按。它们保留方位角的惯性控制：按住施加转动力，松手靠阻尼逐渐减速，反向按键先刹车。头、身体固定为一个始终直立的整体，主体没有独立移动操作。通过武器触地和调整方位来移动；空中挥棍不能凭空推动角色。

武器悬空围绕身体旋转，没有可见连接件。武器内端与身体中心保持固定距离，空隙不参与攻击或格挡判定；武器触地时仍通过游戏中的约束传力，带动身体移动。长柄武器默认悬空距离为 1.35、自身长度为 2.35；短剑的独立参数在 `src/physics.js` 的 `WEAPONS` 中。

例如，从头顶按 W（↑）让武器从正面触地，按 S（↓）则从背面触地。持续朝该方向挥动时，触地点可以撑高并移动身体；A / D（← / →）可同时调整接下来的水平方向。地面与武器碰撞仍会改变转速。批准的动作示意保存在[控制动作视频](docs/control-concept-combinations.mp4)，实现细节见[控制系统说明](docs/CONTROL_SYSTEM.md)。

## 对战规则

- 同一键盘本地双人；默认每方 100 HP，血量归零判负，可再战。菜单可选「双人对战 · 分屏视角」或「双人对战 · 固定视角」。前者并排显示两位玩家的跟随视角；后者使用最初版本的固定高位镜头，在同一画面显示两位玩家。两种对战使用相同的武器、操控和物理规则，重开保留所选模式。
- P1 用 WASD、P2 用方向键；左右键控制角色面向和武器挥动平面的水平转向。在固定视角中，转向仍相对角色面向，镜头不跟随角色转动。
- 头部与躯干伤害相同；同一挥击不会因持续重叠而反复扣血。
- 伤害以接触点朝向对手的相对碰撞速度为基础，叠加命中前约 90 ms 的沿挥动方向净加速度（计入阻尼和转速上限），最高加成 30%，基础单次伤害上限 34；铁战锤的金属头在此基础上乘 1.3，四舍五入后上限 44，锤柄仍使用基础伤害。
- 相同碰撞速度、发力与命中部位下，纯水平转动命中的伤害系数为竖直挥击的 50%；组合动作按接触点朝向对手的横转、竖挥和身体相对移动贡献混合计算。松开转向键后的惯性命中仍会降低横转部分的伤害；与命中方向无关的横向运动不会削弱竖击。伤害调整不改变基础碰撞和格挡冲量。
- 每人另有 100 耐力：W / S（↑ / ↓）每秒消耗 20，A / D（← / →）每秒消耗 8，同时操作叠加。只竖挥约 5 秒耗尽；组合动作约 3.6 秒。放开两轴武器操作 0.5 秒后，每秒恢复 30。反向输入、武器受阻时继续按键仍消耗耐力；同轴相反键抵消后该轴不消耗。转动镜头、被动摆动和碰撞不消耗耐力。
- 耐力低于 25 时，主动驱动力和驱动转速逐渐降低，耗尽时保留 40% 的驱动力及驱动转速目标。反向刹车保留原有响应；松手仍有惯性，力竭不会锁住武器。继续按键不会恢复耐力；暂停、倒数与命中停顿不推进耐力，重开恢复满值。所有模式和三种武器采用相同耐力规则，生命与耐力分别显示。
- 低于 1.65 m/s 的轻触不扣血。向心加速度、碰撞产生的骤停不参与加成。
- 武器互相碰撞可格挡；命中反馈包括短暂停顿、击退、武器受阻、粒子、数字、音效和轻微震屏。系统开启“减少动态效果”时禁用震屏。
- 角斗场边界约束主体，不以掉出场外判胜。角色能被撑起但始终直立。
- 单人练习中青丸不主动操作，但仍会被击退；停止受击 2.5 秒后恢复血量，最低保留 1 HP。
- 分屏对战采用已确认的角色后方远景：从身后略偏 15° 看向前方，使用较缓俯视、55° 透视和 10.5 的默认距离，可看到圆台远侧边缘；镜头柔和追踪武器。A / D（← / →）转动武器与角色面向，镜头的水平朝向保持独立；P1 按住 Q / E、P2 按住句号键和斜杠键（. / ?，无需 Shift）水平转动自己的镜头，松开保持所选角度。两组镜头键的方向已根据实玩反馈反转。双方视角互不影响，对战不使用鼠标控制镜头，重开恢复初始角度。
- 分屏镜头的位置始终跟随自己的角色，并柔和调整武器在画面中的位置。画面边缘检查会在角色头部、身体或标签锚点需要更多空间时立即拉远，空间恢复后再缓慢靠近，防止撑地跳起或击退时看丢自己；对手和整把武器不保证始终在画面内。分屏圆台及物理边界与单人模式一样，扩大至原圆台的三倍半径（19.35）；固定视角对战与木桩练习保留原圆台。
- 单人自由视角只有赤丸，圆台及其物理边界与分屏对战一样，是原圆台的三倍半径，棍子与地面物理规则保持相同。视角从武器侧面稍高处开始，随后柔和追踪武器在画面中的位置；A / D 仍直接转动武器，镜头的水平朝向保持稳定。左侧指示盘显示角色面向和挥动平面相对当前镜头的水平方向。在场景内拖动鼠标旋转视角，滚轮调远近，松手一段时间后缓缓回到起始方向。
- 失焦、切换标签页会自动暂停，防止卡键。

## 文件

- `src/physics.js`：与渲染无关的固定步长物理、约束冲量、伤害。
- `src/scene.js` 和 `src/ArenaCanvas.jsx`：角斗场、角色、武器、拖尾、粒子与 React Three Fiber 渲染循环。
- `src/game-session.js`：对局状态、键盘输入和固定步长物理循环。
- `src/App.jsx`：React 菜单、HUD、暂停和结算。
- `src/Armory.jsx` 和 `src/weapon-catalog.js`：兵器展示、特点说明、双方开打前选择。
- `src/weapon-visuals.js`：模型轴向、握持端和连续旋转姿态。
- `src/audio.js`：Web Audio 合成音效，无外部音频资源。
- `src/style.css`：界面布局与窄屏适配。
- `public/models/polearm.glb`：从 Tripo 导出的武器模型压缩后的游戏用副本；原始文件保存在 `assets/source/`。
- `public/models/sword.glb`：Tripo 公共作品的轻量化本地试验副本；发布或分发前须核对原作者的使用许可。
- `public/models/hammer.glb`：用户选定的铁战锤，约 2.8 MB、8 万三角面、1K 贴图；原始导出保存在 `assets/source/`。
- `scripts/prepare-weapon.mjs`：校验新导出布局、减面和缩小贴图（需要 Python 3 与 Pillow）。
- `scripts/prepare-sword.mjs`：从原始短剑 GLB 生成较轻的游戏副本。
- `electron/main.cjs`：沙盒化 Electron 开发窗口，不开放 Node.js 或 IPC 给渲染器。
- `tests/physics.test.js`：物理规则与稳定性回归测试。

开发者工具控制台可通过 `window.__arena.snapshot()` 只读检查当前对局，通过 `window.__arena.rendererInfo()` 查看渲染资源计数。

## 原型边界

当前是同屏键盘原型，没有联网、AI 对手或手柄控制。目前有快挥短剑、长距长柄刀和慢速重击铁战锤，可在兵器库开打前选择。后续武器和最终平衡仍待设计与实玩；锤头使用多个胶囊体近似，布条不参与碰撞。物理采用专门为“直立身体 + 两自由度武器”构建的简化模型，角色碰撞使用胶囊近似。质量、阻尼、摩擦、驱动力等参数集中在 `CONFIG`，可在实玩后继续调校。部分键盘有多键冲突，可以先在练习模式验证操作。
