# 音频素材库

游戏使用的音频统一存放在此目录。

- `sfx/`：碰撞、挥动、菜单等音效。
- 后续背景音乐放入 `music/`，角色语音放入 `voices/`。
- 文件名使用英文小写和连字符；新增素材时在下表记录来源与用途。

| 文件 | 用途 | 来源 |
| --- | --- | --- |
| sfx/weapon-clash.m4a | 武器相撞（clash），音量随碰撞力度变化 | 用户提供的 copy_477441E3-12EB-47C8-B409-25773B8AF1CA.MOV，提取完整音轨 |

由 src/audio.js 加载。关闭声音时不播放；文件加载失败时使用原合成碰撞声。
